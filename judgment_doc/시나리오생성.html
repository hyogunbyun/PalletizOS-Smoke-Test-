조사 결과 → 시나리오 바꾸는 법

DESIGN
조사 목록에서 "누르면 무엇이 바뀌나"와 "무엇과 같아야 하나"를 찾아 시나리오로 만듭니다. 예: 위 Digital Output 표 → I02
조사에서 발견한 것항목만든 확인 규칙
1번 행 Value 'Off' 옆에 Test 'On' 버튼I02On 누르면 Value가 On으로 바뀜 + 로그 setDigitalOutput 200 OK → Off로 원복
Recipes 상단 '3' 'Recipe' 글자 + 목록 행, 한 행에 'In Use'R01개수 표시 = 행 수, In Use 레시피 = Home 레시피
Search 입력칸R03일부 글자 → 해당 행만 / 없는 단어 → 0개 / 지우면 전체 복귀
행 끝 'menu' 버튼 (⋮)R04메뉴 6개 표시 → ESC로 닫힘 (Delete·Export는 누르지 않음)
Create Recipe 버튼R05편집기 열림 → X로 닫으면 레시피 수 그대로 (저장 안 함)
Settings Save가 평소 비활성S02Unit을 바꾸면 Save 활성 → 되돌리면 다시 비활성 (저장 안 함)
원칙값을 바꾸는 시나리오는 끝에서 반드시 원래대로 되돌린다. 저장·삭제·내보내기처럼 되돌릴 수 없는 버튼은 "버튼이 있는지"까지만 확인한다.

녹화로 추가 — 누르면 시나리오가 된다

RECORD
STEP 1
표시창 ＋ 추가 또는 PalletizOS_record.bat
STEP 2
이름 적고 ● 녹화 시작 (자동화는 일시정지)
STEP 3
앱에서 평소처럼 클릭 → 단계가 쌓임
STEP 4
완료 → 끝에 보여야 할 문구 고르기
STEP 5
저장 → 다음 실행부터 C## 포함
자동으로 일어나는 일: 클릭할 때마다 녹화기가 그 자리의 화면 요소를 읽어 "무엇을 눌렀는지"를 아래 규칙으로 기록합니다. 좌표가 아니라 요소를 기록하므로 창 위치·크기가 달라도 재생됩니다.
누른 것기록 방법
이름 있는 버튼·탭·항목종류 + 이름 + 같은 이름 중 몇 번째 — 예: Button 'Settings'
이름 없는 아이콘 버튼가장 가까운 이름 있는 요소 기준 상대 위치 — 예: 'Release Vacuum' 기준 −182, −47
접힌 좌측 메뉴 아이콘펼쳤을 때의 메뉴 이름으로 바꿔 기록
입력칸에 친 글자값이 바뀐 것을 감지해 "입력" 단계로 기록 · 비밀번호는 기록 안 함
기록하지 않는 것: 드래그 · 스크롤 · 앱 바깥 클릭. 녹화한 계정이 Admin이면 실행 때 자동으로 Admin 전환 후 재생.
